The agent that lives in your browser

A complete single-file web app for the Gemini API. Save your key, fetch live models, chat with the selected model, and refactor code — all in one page, no build step, no dependencies.

Free tier Gemini 3 models 1M token context Refactoring agent 10 models bundled

The Gemini CLI brings Gemini directly into your terminal. This web app mirrors that experience for the browser: same free tier, same models, same extensibility — but with a magazine interface and a built-in code refactoring agent that streams structured output and shows you a real diff before you apply anything.

From your prompt to the model — without ever leaving the page.

What you can do here

  • Save your API key — stored locally in your browser, never sent anywhere except Google's API.
  • Fetch the live model list — or use the bundled fallback list of ten current models.
  • Chat with the selected model, with a scrolling conversation history.
  • Refactor code — paste source, describe the change, get a diff, apply when ready.
  • Keyboard-first navigation — 1–6 for sections, R to refresh.

Get started in three steps

  1. Get a free API key from Google AI Studio.
  2. Paste it into the API Key tab and click Save.
  3. Open the Models tab, fetch the list, and pick one.
Privacy. Your API key is stored only in this browser's localStorage. It is sent only to generativelanguage.googleapis.com, directly from your browser. No intermediate server, no logging.

Save your API key

Your key is stored only in this browser. It is sent only to Google's Generative Language API, directly from your browser.

Step 1 · Get a key

Open Google AI Studio, sign in with your Google account, and click Create API key. The free tier includes 60 requests per minute and 1,000 requests per day with Gemini 3 models.

Step 2 · Paste and save

How validation works

When you click Validate key, the app makes a small request to the models.list endpoint. If the key is valid you will see a green confirmation and the model list will be populated. If it is invalid you will see the exact error message Google returns.

Note. Browser CORS policy allows direct calls to the Generative Language API. If you are behind a corporate proxy that blocks it, the fallback model list will still work, but chat and refactoring will not.

Environment overrides

If you prefer not to persist the key, you can set it for the current session only by opening the browser console and running:

// set a key for this session only sessionStorage.setItem('gemini.apiKey', 'AIza...')

How the agent works

  1. Your source code and instructions are assembled into a prompt with a strict system instruction.
  2. The prompt is sent to the selected model with a temperature of 0.2 for reproducibility.
  3. The model returns the complete refactored file inside a single triple-backtick code fence.
  4. The app extracts the fence, computes a unified diff against the source, and displays both.
  5. You review, then apply — the original source is replaced in the editor, not on disk.
Tip. For large files, choose a Pro-tier model. The Flash-Lite tiers are excellent for small scripts and snippets but may truncate on very long inputs.

About

This is a single-file, browser-rendered web app for the Gemini API. It is one HTML document with embedded CSS and JavaScript — no build step, no dependencies, no server. The magazine aesthetic is a presentation layer over a working API client and code refactoring agent.

What this app actually does

  • Saves a Gemini API key in browser localStorage.
  • Fetches the live model list from the Generative Language API.
  • Falls back to a bundled list of ten models when the API is unreachable.
  • Chats with the selected model, keeping history in memory.
  • Refactors code with a strict system prompt and shows a unified diff.

The Gemini CLI project

  • Licence — Apache License 2.0

API reference

  • GET /v1beta/models — list models
  • POST /v1beta/models/{model}:generateContent — generate a response
  • Auth via ?key=API_KEY query parameter
